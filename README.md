# P2P Calculator

Веб-приложение на PHP для учёта P2P-сделок, расчёта прибыли, управления банками и просмотра статистики. Проект подготовлен для размещения в GitHub.

## Возможности

- Регистрация и вход пользователей.
- Калькулятор P2P-сделок с комиссиями, прибылью, ROI и спредом.
- История сделок и экспорт CSV.
- Учёт банков и лимитов оборота.
- Настройки профиля, языка и темы.
- Административная панель для просмотра пользователей, блокировки аккаунтов и настройки сайта.
- SQLite для хранения данных.
- CSRF-проверки, хеширование паролей и серверная проверка доступа.

## Требования

- PHP 8.1 или новее.
- Расширения `PDO`, `pdo_sqlite` и `mbstring`.
- Возможность записи в каталог приложения (для файла базы SQLite).

## Запуск локально на Windows 10

1. Установите PHP 8.1+ с расширениями SQLite и mbstring.
2. Откройте PowerShell в папке проекта.
3. Установите переменную окружения для создания первого администратора:

   ```powershell
   $env:APP_ADMIN_KEY = "ЗАМЕНИТЕ_НА_ДЛИННЫЙ_СЛУЧАЙНЫЙ_СЕКРЕТ"
   ```

4. Запустите встроенный сервер PHP:

   ```powershell
   php -S 127.0.0.1:8000
   ```

5. Откройте `http://127.0.0.1:8000` в браузере.
6. Выберите «Настроить первого администратора», введите тот же секретный ключ, никнейм, Telegram и пароль администратора длиной не менее 12 символов.
7. После создания администратора войдите в аккаунт. Не публикуйте секретный ключ и не добавляйте его в GitHub.

При первом запуске приложение создаст файл `p2p-calculator.sqlite` рядом с `index.php`.

## Публикация в GitHub

1. Создайте новый пустой репозиторий на GitHub.
2. Распакуйте архив проекта.
3. Загрузите в репозиторий `index.php`, `README.md`, `.gitignore` и каталог `.github`.
4. Убедитесь, что база данных, секреты и пользовательские данные не попали в репозиторий.

В репозиторий не следует добавлять `p2p-calculator.sqlite`, реальные пароли, ключ `APP_ADMIN_KEY` или резервные копии базы.

## Развёртывание на хостинге

Используйте хостинг с PHP 8.1+ и SQLite, включите HTTPS и задайте `APP_ADMIN_KEY` в настройках окружения сервера до создания первого администратора. Убедитесь, что файл базы данных и резервные копии недоступны для скачивания через веб-сервер. По возможности храните базу вне публичного web-каталога.

## Важные ограничения

Это стартовая версия приложения, а не подтверждённый аудит безопасности. Перед использованием с реальными данными проверьте бизнес-логику и права доступа, настройте резервное копирование и HTTPS, обновите серверное ПО и проведите тестирование. Абсолютную защиту от взлома гарантировать невозможно.
